# FAHAD STUDIO

Personal production studio with two sections:
- **Video** — motion, product ads, web showcases, identity reels and 3D on Remotion + React Three Fiber.
- **Web** — motion websites on Vite + React + GSAP (`web/`), with an interaction lab, media pipeline and automated QA. See [docs/WEB.md](docs/WEB.md).

```bash
npm ci            # install exact locked versions
npm run doctor    # environment check
npm run studio    # open Remotion Studio (http://localhost:3000)
npm run web:install && npm run web:dev   # web section (http://127.0.0.1:5173/)
```
