# Manual checks the QA script cannot judge

- Composition: does the first screen read in one second? Is the key visual dominant, with everything else supporting it?
- Pinned scene: capture frames along the pin (e.g. scroll 0, 25%, 50%, 75%, 100% of its length) at 1440×900 with `?capture=1` and check transitions have a clear start and end.
- Type: line lengths 45–75 characters for body, no widows in display lines, consistent baseline rhythm.
- Arabic: no letter-spacing, correct punctuation side, mixed Arabic/Latin order, digits.
- Motion feel: easing consistent, nothing moves without a reason, hovers subtle.
- Content honesty: concept work labelled as concept; no invented clients, numbers, awards or contact data; forms that don't submit say so.
