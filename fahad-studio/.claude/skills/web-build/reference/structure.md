# Web section structure (fahad-studio/web)

- `index.html`, `form/`, `lab/`, `concepts/` — Vite multi-page entries (`vite.config.ts` → `build.rollupOptions.input`).
- `src/shared/fx/` — reusable effects: `motion.ts` (GSAP + ScrollTrigger, reducedMotion, finePointer, capture mode, `trackFx` leak registry), `useGsap.ts` (gsap.context + revert), `MaskHeadline`, `Reveal`, `Parallax`, `PinnedScene`, `PerspectiveShelf`, `CursorReveal`, `VideoBackground`, `Picture`.
- `src/shared/styles/` — `fonts.css` (local OFL fonts, Arabic via unicode-range), `base.css` (reset, focus ring, skip link, reduced motion), `fx.css` (component styles, hover/focus).
- `src/shared/media-manifest.json` — generated by `npm run assets`; never edit by hand.
- `src/sites/form/` — proof site: `content.ts` (all copy/data), `App.tsx`, `sections/`, `form.css`.
- `src/lab/` — interaction lab with remount ×5 leak test.
- `src/concepts/` — original concept screens (1440×900), captured with `npm run capture:concepts`.
- `scripts/` — `lib.mjs`, `capture-concepts.mjs`, `prepare-assets.mjs`, `qa.mjs`, `capture-showreel.mjs`.
- `public/fonts`, `public/media` (generated), `public/concepts` · `assets-src/` (raw, regenerable) · `assets-registry.json` (generated) · `qa/` (report + screenshots).
