# X Arabic Clean — ترجم نظيف

إضافة متصفح تعمل داخل
**x.com**
و
**twitter.com**
تضيف زر «ترجم» على مقاطع الفيديو العامة.
عند الضغط عليه تفحص المقطع أولًا (الصوت + لقطات من الصورة)، فإذا كان نظيفًا تترجمه للعربية وتعرض الترجمة فوق الفيديو متزامنة مع الكلام.
إذا احتوى على محتوى غير مناسب تمنع الترجمة وتخفي المقطع.

> ملاحظة: ملفات مشروع ميزان الموجودة في جذر المستودع
> (`index.js` و `Mizan v15 — Reliable (1).json`)
> لم تُمسّ. مشروع «ترجم نظيف» كله داخل المجلدين
> `extension/`
> و
> `server/`.

---

## البنية

```
extension/                 إضافة Chrome (Manifest V3 + React + TypeScript + Vite + Tailwind)
  public/manifest.json     تعريف الإضافة والصلاحيات
  src/content/             يعمل داخل صفحة X: MutationObserver، الأزرار، الترجمة فوق الفيديو
  src/background/          Service Worker: الوسيط الوحيد مع الخادم
  src/components/          واجهات React (شريط التحكم، الترجمة، ترجمة التغريدة)
  src/lib/                 الإعدادات، التقاط الصوت، جلسة الترجمة، WebVTT/SRT
  src/pages/               صفحات الإعدادات والنافذة المنبثقة والخصوصية
  src/styles/              Tailwind
  tests/unit/              اختبارات Vitest
  tests/e2e/               اختبارات Playwright على صفحة تحاكي X
server/                    خادم Node.js + Express + TypeScript
  src/routes/              مسارات API
  src/services/            مسار المعالجة، WebVTT/SRT
  src/providers/           مزودو التفريغ والفحص والترجمة (OpenAI / Anthropic / تجريبي)
  src/moderation/          القاموس المحلي وسياسة القرار الصارمة
.env.example               نموذج ملف البيئة (المفاتيح على الخادم فقط)
PRIVACY.md                 سياسة الخصوصية المختصرة
```

## كيف تعمل

1. تكتشف الإضافة المقاطع عبر
   `MutationObserver`
   أثناء التمرير، وتضيف زرًا واحدًا فقط لكل مقطع.
2. عند الضغط على «ترجم» تلتقط الإضافة صوت المقطع **أثناء تشغيله في متصفحك**
   (`HTMLMediaElement.captureStream`)
   على دفعات قصيرة (8 ثوانٍ افتراضيًا) مع لقطتين مصغّرتين من الصورة لكل دفعة.
3. يرسل
   Service Worker
   الدفعة إلى الخادم:
   تفريغ ← فحص (نص + صور) ← ترجمة (فقط إذا كانت النتيجة نظيفة) ← WebVTT/SRT.
4. تظهر الترجمة فوق الفيديو تدريجيًا ومتزامنة مع الكلام.
5. **أي دفعة مرفوضة أو غير مؤكدة توقف كل شيء وتحذف كل الترجمة السابقة للمقطع.**

### قاعدة الأمان

| النتيجة | التصرف |
|---|---|
| `clean` | يُسمح بالترجمة |
| `rejected` | تُمنع الترجمة، لا يُعرض النص الأصلي، ويُخفى المقطع |
| `uncertain` | تُمنع الترجمة ويُطلب اختيار مقطع آخر |

- تعذّر فحص الصورة = `uncertain`.
- خطأ من مزود الفحص = `uncertain`.
- رفض النموذج للطلب = `uncertain`.
- لا يعمل الخادم بفحص تجريبي مع تفريغ أو ترجمة حقيقية (يتحول الكل لوضع التجربة).

## التشغيل المحلي

المتطلبات: Node.js 20 أو أحدث، و Google Chrome.

```bash
npm install          # من جذر المشروع (يثبت الخادم والإضافة معًا)
npm run build        # يبني الخادم والإضافة
npm run start:server # يشغّل الخادم على http://localhost:8787
```

للتطوير مع إعادة تشغيل تلقائية للخادم:

```bash
npm run dev:server
```

### تثبيت الإضافة في Chrome

1. افتح `chrome://extensions`
2. فعّل «وضع المطوّر» (Developer mode) أعلى الصفحة.
3. اضغط «تحميل إضافة غير مضغوطة» (Load unpacked).
4. اختر المجلد `extension/dist`
5. افتح https://x.com وشغّل أي مقطع، ثم اضغط «ترجم».

بعد أي تعديل على الكود: `npm run build` ثم زر التحديث ↻ على بطاقة الإضافة.

## Mock Mode (وضع التجربة)

إذا لم توجد مفاتيح API يعمل الخادم تلقائيًا في وضع التجربة:

- النص المعروض فوق المقاطع **نص تجريبي ثابت** (درس عن زراعة حديقة) وليس ترجمة حقيقية للمقطع.
- تظهر شارة «تجريبي» على الأزرار والترجمات.
- تظهر في الإعدادات رسالة: «وضع التجربة مفعّل — أضف مفاتيح API لتشغيل الترجمة الحقيقية.»
- القاموس المحلي للفحص يعمل فعليًا (حالة الرفض ليست مصطنعة).
- من الإعدادات ← الخادم ← «سيناريو التجربة» يمكنك تجربة: مقطع نظيف / مقطع مرفوض / حالة غير مؤكدة.

لفرض وضع التجربة حتى مع وجود مفاتيح:
`PROVIDER_MODE=mock`
في ملف
`.env`.

## إضافة مفاتيح API (التشغيل الحقيقي)

```bash
cp .env.example .env
```

ثم عبّئ في `.env`:

| المتغير | الاستخدام |
|---|---|
| `OPENAI_API_KEY` | التفريغ الصوتي (Whisper) + فحص النص والصور (omni-moderation) — **مطلوب للتشغيل الحقيقي** |
| `ANTHROPIC_API_KEY` | الترجمة عبر Claude (اختياري؛ بدونه تُستخدم OpenAI للترجمة) |
| `TRANSCRIPTION_PROVIDER` / `MODERATION_PROVIDER` / `TRANSLATION_PROVIDER` | تبديل المزود لكل مرحلة: `openai` أو `anthropic` أو `mock` |
| `PROVIDER_MODE` | `auto` (افتراضي) أو `mock` أو `live` (يرفض التشغيل إذا نقصت المفاتيح) |
| `ACCESS_TOKEN` | كلمة سر اختيارية تحمي خادمك؛ ضع نفسها في إعدادات الإضافة |
| `ALLOWED_EXTENSION_IDS` | قصر الوصول على معرّف إضافتك فقط |

أعد تشغيل الخادم. ستظهر في الطرفية: «الوضع: حقيقي (Live)».

**المفاتيح تبقى على الخادم فقط.** الإضافة لا تحتوي أي مفتاح، وأمر البناء يفحص ذلك تلقائيًا.

لإضافة مزود جديد: أنشئ صنفًا يطبّق الواجهة المناسبة في
`server/src/providers/types.ts`
ثم سجّله في
`server/src/providers/index.ts`.

## واجهة الخادم API

| المسار | الوصف |
|---|---|
| `GET /api/health` | الحالة ووضع التشغيل (mock/live) |
| `POST /api/process-video` | المسار الكامل لدفعة صوتية: تفريغ ← فحص ← ترجمة ← WebVTT |
| `POST /api/transcribe` | تفريغ مع التوقيت (يُفحص قبل الإرجاع؛ المرفوض لا يُعاد نصه) |
| `POST /api/moderate` | فحص نص و/أو صور، يعيد الحالة فقط |
| `POST /api/translate` | ترجمة نص تغريدة أو أسطر مؤقتة (بعد الفحص) |
| `POST /api/create-vtt` | تحويل أسطر مترجمة إلى WebVTT و SRT |

مثال نتيجة ناجحة:

```json
{
  "status": "approved",
  "language": "en",
  "translationLanguage": "ar",
  "segments": [{ "start": 0.0, "end": 3.4, "original": "Hello everyone", "translated": "مرحبًا بالجميع" }],
  "vtt": "WEBVTT...",
  "srt": "1\n00:00:00,000 --> ...",
  "mock": false
}
```

مثال نتيجة مرفوضة:

```json
{ "status": "rejected", "reason": "المقطع لا يطابق سياسة المحتوى النظيف" }
```

## حدود التعامل مع مقاطع X/Twitter

- نعالج فقط المقاطع العامة التي **يشغّلها المستخدم بنفسه** في صفحته ويختار ترجمتها.
- لا نحمّل ملفات الفيديو من خوادم X؛ نلتقط الصوت من عنصر الفيديو أثناء تشغيله (مثل ما تسمعه أنت).
- لذلك الترجمة تظهر تدريجيًا أثناء التشغيل (أول سطر بعد بضع ثوانٍ)، وليس قبل بدء المقطع.
- إذا قفزت داخل المقطع تُهمل الدفعة الجارية ويُستأنف الالتقاط من الموضع الجديد.
- عند التمرير بعيدًا يحذف X التغريدة من الصفحة، فتتوقف المعالجة وتُحذف نتيجتها.
- لا نعمل في الرسائل الخاصة أو الإعدادات، ولا على تغريدات الحسابات المحمية.
- صور GIF المتحركة لا صوت لها فلا يظهر عليها الزر.
- اللغة الإنجليزية مدعومة أولًا؛ بقية اللغات في الإعدادات تجريبية (حسب دعم مزود التفريغ).
- يعتمد اكتشاف العناصر على سمات `data-testid` في X؛ إذا غيّر X بنية صفحته قد يلزم تحديث المحددات في
  `extension/src/lib/x-dom.ts`.

## تنبيه مهم

**الإضافة لا تتجاوز أي حماية في X ولا أي DRM، ولا تنتهك حقوق المحتوى.**
المقاطع المحمية ترفض الالتقاط فتتوقف الإضافة.
الترجمة للاستخدام الشخصي للمشاهدة فقط، وحقوق المقاطع لأصحابها.
استخدام الإضافة يخضع لشروط استخدام X ولشروط مزودي الذكاء الاصطناعي الذين تختارهم.
